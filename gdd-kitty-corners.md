# Kitty Corners — Game Design Document
**Сборочная версия.** Обновлено: 08.07.2026.
Источник истины по UI: макет `kitty-corners-screens-v22.html` (лежит рядом). При расхождении текста и макета приоритет у макета.

---

## 1. Концепция

- Жанр: логическая головоломка, клон LinkedIn Queens / Star Battle 1★.
- Тема: коты; каждый кот занимает «свою территорию».
- Позиционирование: **дзен** — без таймера, без давления; спокойная казуальная сессия.
- Платформа: **Playgama** (web), mobile-first, портрет.
- Название: **Kitty Corners** — тройной смысл: кошачьи уголки + идиома kitty-corner («по диагонали», ключевое правило) + отсылка к народной игре. Отклонены: Cat Queens (коллизия + казино-SEO), Catnook.
- Визуальный жанр: casual-cute в духе MeowDoku, но с собственной айдентикой (см. §6). Прямое копирование чужого арта запрещено.

## 2. Правила и управление

Правила (тексты в игре — EN, как в чипах над полем):
1. **1 Cat per color** — ровно один кот в каждом цветном регионе.
2. **1 Cat per column and row** — ровно один кот в каждой строке и каждом столбце.
3. **Cats cannot touch** — коты не касаются даже по диагонали.

Управление:
- Тап по клетке — поставить/снять крестик (ручная разметка).
- **Лонг-пресс ~350–400 мс** с анимацией «кольца зарядки» — коммит кота в клетку.
- Ошибочный коммит → −1 сердце + визуальный отклик. Коммит верен только если клетка входит в единственное решение уровня: у каждого кота ровно одно легальное место. Любая другая постановка — ошибка (−1 сердце), даже если она пока не конфликтует с уже стоящими котами. Это исключает тупики из локально-легальных, но неверных ходов (ср. QA KC-4); честно, т.к. все уровни решаются солвером логикой без угадывания.

Сознательно отсутствуют (скилл-слой, решение зафиксировано): авто-тени от котов, undo, ластик-режим. Ручная разметка — часть мастерства игрока.

**Стартовый кот (Р-36):** уровень начинается с как минимум одного предустановленного кота (клетка из решения; по умолчанию — кот самого маленького или второго по маленькости региона, чередуется по чётности id уровня: мини-регионы — самые зажатые, отдавать их бесплатно выгоднее для интереса; переопределяется полем `givens` в данных уровня). Он неснимаем. При открытии уровня играет интро: анимация появления кота → с небольшой задержкой от него во все стороны волной прорисовываются авто-крестики (его строка/столбец/регион/соседи). Эти крестики — обычные пометки (игрок может их снять). Исключение из запрета авто-теней: действует только для стартового кота в момент интро; ввод на время интро заблокирован; при prefers-reduced-motion интро пропускается.

### 2.1 Туториал (Р-41)

Первый запуск: Play → слайды «How to play» (3 карточки: правила / управление / сердца-стрик) → guided-уровень 4×4 → обычный Level 1. Кнопка Skip в шапке guided-уровня; флаг `tutorialDone` персистится — повторно не показывается. Слайды доступны всегда: «?» на главной и «How to play» в настройках (единый компонент).

Guided-уровень — заскриптованная песочница без сердец, рекламы и таймера (`src/lib/tutorial.ts`): ручной 4×4 с уникальным решением, стартовый кот с интро-волной как в бою; шаги ведут по реальной цепочке дедукций уровня — «у региона осталась одна клетка» (лонг-пресс кота), ручные крестики по следствиям кота (тап), финальный кот → волна радости → «Start Level 1». Ввод ограничен подсвеченными клетками (persistent-пульс), неверные действия молча игнорируются. Консистентность скрипта и уровня закреплена тестом `tests/tutorial.test.ts`.

## 3. Сердца, стрик, поражение

- 3 сердца на уровень. Потеря сердца не ломает стрик.
- 0 сердец → экран поражения. Иерархия действий (Р-25):
  1. **Rewarded «Get +1 ♥ and keep going»** — доминирующая кнопка (revive, приоритет по текущему макету).
  2. «Restart level» — вторичная.
  3. «Quit to menu» — тихая ссылка.
- Предупреждение на экране: «Your N level streak will end here».
- Стрик ломается рестартом/выходом после полного слива сердец; revive его сохраняет.

> ⚠️ **Флажок перед сабмитом:** ранее фиксировался конфликт revive-механики с политикой Playgama (тогда решением была замена на «Skip level»). Текущий макет возвращает «+1 ♥» как приоритетный. Сверить с актуальной политикой платформы до релиза.

### 3.1 Очки (Р-42)

За победу: **очки = База × Время × Чистота × Глазомер × Помощь**, округление до 5. Поражение и skip очков не дают. Кумулятивная сумма `totalScore` персистится — будущее значение лидерборда Playgama; каждый номер уровня набирается один раз (номер растёт только на победе). Стрик на очки не влияет.

- **База** = 100 × `meta.steps` уровня (шаги солвера, 10–26): сложность оплачивается автоматически.
- **Время**: пар = 12 × steps сек; множитель `clamp(1.5 − 0.5·t/par, 0.5, 1.5)` — медленная игра не обнуляет очки (дзен), только теряет бонус.
- **Чистота**: 0 ошибок ×1.0, одна ×0.6, две ×0.35.
- **Глазомер**: доля самостоятельно помеченных ✕-клеток r = xCells/(n²−n); множитель 1 + 0.4·(1−min(r,1)). Бонус, не штраф: разметка — легитимное мастерство (§2). Авто-крестики стартового кота не считаются; снятие пометки её «не возвращает».
- **Помощь**: хинт ×0.8 за каждый, автокот ×0.5 — очки нельзя купить просмотром рекламы.

Идеал ~2.1 × базы. Показ: пилюля на Victory (+очки и Total). Реализация: `src/lib/score.ts` (чистый модуль, тесты `tests/score.test.ts`); счётчики прогона в `game.ts`.

### 3.2 Лидерборд (Р-43)

Один лидерборд `total_score` (кумулятивные очки Р-42) через Playgama Bridge SDK (`bridge.leaderboards`), объявлен в `playgama-bridge-config.json`. Сабмит — fire-and-forget на каждой победе (ошибка сабмита не ломает победный флоу).

Четыре режима по `leaderboards.type` платформы: `not_available` — все входы в лидерборд скрыты (сама Playgama сейчас без лидербордов); `in_game` (Yandex, Y8, bitquest) — свой UI-оверлей на `getEntries`; `native` (MSN, Lagged и др.) — только сабмит, борд рисует платформа; `native_popup` (Facebook) — сабмит + `showNativePopup`. Входы: кнопка-кубок на главной и ссылка на Victory (видны только в `in_game`/`native_popup`). Локально/в превью без SDK — мок `in_game` с фейковыми записями (как мок-паттерн рекламы). Реализация: `src/lib/leaderboard.ts`, UI `components/LeaderboardOverlay.svelte`, тесты `tests/leaderboard.test.ts`.
**Десктоп-панель (Р-44):** в landscape/desktop при режиме `in_game` рейтинг постоянно на экране справа от поля (правая колонка грида: панель + кнопки помощи); та же панель видна на Victory. Хореография стартует при показе win-экрана (не раньше): чип «+очки» перелетает со стороны поля в панель (~0.8s), затем таблица обновляется и строки переезжают на новые места (FLIP, svelte animate). Своя строка подсвечена и вспыхивает при приземлении. При prefers-reduced-motion — мгновенное обновление без полёта. Состояние панели живёт в module-scope (`panelEntries`/`pendingGain` в `leaderboard.ts`), поэтому анимация переживает смену экрана game → victory. Компонент: `components/LeaderboardPanel.svelte`.
**Мобильная строка ранга (Р-45):** в портрете панели нет — на win-экране под пилюлей времени компактная строка: без изменения позиции «🏆 #N your rank», при подъёме — «#старый (зачёркнут) → #новый you climbed!» с анимацией всплытия нового ранга (задержка ~1.1s после появления экрана). Тап открывает полный оверлей лидерборда. Ранг считается локально по снапшоту таблицы до победы (1 + число результатов выше); в landscape строка скрыта — там движение показывает панель. Сторы `winRanks` в `leaderboard.ts`.



## 4. Монетизация

100% реклама через **Playgama Bridge SDK**:
- **Interstitial** на границах уровней; таймаут показа 180 с.
- **Rewarded video**: (а) «+1 ♥» на экране поражения; (б) лампочка-хинт — **первая подсказка на уровне бесплатна, последующие rewarded** (Р-56, §5.2); (в) автокот (см. §5.2). У rewarded-элементов бейдж «▸ ad» (у лампочки бейдж условный — появляется после бесплатной подсказки).
- Премиум-тира нет.

## 5. Экраны (спека по макету v22)

### 5.1 Main
- Верх: иконки-кнопки настройки (слева) и «?» (справа).
- Центр: лого-знак 136px + словомарка «Kitty / Corners» (вторая строка акцентная), теглайн «a cozy logic puzzle».
- Фон: диагональная дорожка лапок (фирменный мотив, opacity 50%).
- Низ: чип стрика (пламя + «N level streak»), CTA **Play** с подписью «Level N».
- Баннеров нет.

### 5.2 Board (игровой экран)
- Шапка: «Level N» (слева) · сердца 33px (центр) · шестерёнка (справа).
- Полоса правил: 3 чипа «мини-сетка 3×3 (40px) + текст» (реф-компоновка):
  - per color: голубой регион-лесенка, кот внутри, крестики на остальных клетках региона;
  - column and row: кот сверху-в-центре, крестики по его строке/столбцу;
  - cannot touch: кот в центре, все 8 соседей закрещены.
  Чипы плоские (без объёмного края) — «нажимаемость» зарезервирована за кнопками.
- Поле: квадрат, внешняя рамка 3px ink r14. Продовые размеры 6×6–10×10. Максимум поля: 372px для 6×6–8×8, 44·N px для 9×9–10×10 (клетка ≥40px гарантируется при достаточной ширине вьюпорта; на узких экранах ~390px клетка 10×10 ужимается до ~35px — компромисс по QA KC-2). Поле дополнительно ограничено доступной высотой (ландшафт/низкие iframe, QA KC-1).
- Низ: **две круглые кнопки 60px** (акцент, физика проседания, бейдж «▸ ad» снизу по центру):
  - голова кота — **автокот**: ставит одного верного кота (предложение: лимит 1/уровень, дальше кнопка гаснет);
  - лампочка — **обучающая подсказка** (Р-57..Р-61): показывает следующий не сделанный логический шаг из лога солвера как связку «баннер-объяснение над полем (поверх трёх чипов правил) + подсветка». Кнопка видна всегда (не только при поддержке rewarded); первая подсказка на уровне бесплатна, дальше rewarded (Р-56). Тап **всегда** даёт видимый результат — показ подсказки или тост при отказе рекламы, молчаливого no-op быть не должно (QA KC-6).
- **Подсказка — что показывает.** Берётся первый шаг лога солвера, ещё не отражённый на доске (уже сделанные пропускаются). Два вида:
  - *«сюда встаёт кот»* (place): в группе — регионе/ряду/столбце — осталась одна свободная клетка. Подсвечиваем клетку-цель «кошачьим» свечением + группу-причину; баннер «В этом ряду свободна одна клетка — кот только сюда». Ход всё равно делает игрок (в отличие от автокота, Р-59).
  - *«сюда нельзя, помечай лапками»* (eliminate): клетки надо вычеркнуть. Три причины — тень стоящего кота (ряд/столбец/цвет/соседи), регион заперт в одной линии, голодание чужой группы. Подсвечиваем клетки-цель (лапки, тёплая пульсация) + зону-причину (тихая обводка); баннер объясняет почему.
  - фолбэк: если подходящего шага нет — мягкая подсказка «Где-то здесь прячется кот 🐾» + подсветка клетки решения, чтобы лампочка не «глохла».
- **Тексты подсказок** — в голосе игры, по **цвету** региона (Р-39), не по букве id; технические строки солвера в UI не попадают (Р-60). Баннер держится до первого клика игрока (куда угодно) — авто-таймера нет; закрывается кликом в любом месте, по «×» или открытии настроек. Позиция — сверху поля, поверх полосы из трёх чипов правил. При `prefers-reduced-motion` баннер и подсветка статичны, содержание идентично (QA KC-9).
- **QA подсказки:** первая подсказка на новом/перезапущенном уровне — без рекламы, счётчики сбрасываются в `loadLevel` (QA KC-7); подсказка не предлагает стартовых котов `givens` и уже занятых/помеченных клеток, цель place — только пустая клетка (QA KC-8). `runHints` растёт на каждую показанную подсказку (вкл. бесплатную) и идёт в скор (Р-42, Р-61).
- Таймер не показывается (время меряется скрыто, отчёт на победе).

### 5.3 Settings (оверлей = пауза)
- Поле под оверлеем: blur(6px) + затемнение.
- Дефолты тумблеров: Sound — on, Vibration — off, Pattern marks — off.
- Лист: Continue (CTA) · тумблеры Sound / Vibration / **Pattern marks** (запасное кодирование регионов для дальтоников) · How to play · Restart level (красный, требует подтверждения) · Quit to menu (ссылка).

### 5.4 Defeat
- Грустный маскот (Round-sad: прикрытые глаза, слеза, поникшие усы, приглушённый румянец).
- Три сердца-выемки 45px → заголовок «Out of hearts» → плашка-предупреждение о стрике → кнопки по иерархии §3.

### 5.5 Victory
- Маскот Round → «Level N done!».
- **Карточка Win streak** (фичекарта, реф Arrows): заголовок капсом без иконки → крупное пламя + число + «+1» (pop-анимация) → трек узлов-лапок (пройденные / текущий укрупнённый с анимацией / следующий пунктиром, подписи-номера) → «Best streak · N».
- Прогресс (номер уровня) сохраняется в момент победы, не по «Next level» (QA KC-3); «Your time» считает только активную игру — без интро, паузы, рекламы и экрана поражения (QA KC-5).
- Пилюля «Your time M:SS». Кнопка «Next level». Конфетти (отключается при prefers-reduced-motion).

### 5.6 Cat lab (внутренний инструмент, в прод НЕ идёт)
Экран выбора маскота из 11 вариантов с превью 88/44/26px и живым применением. Оставлен в макете как архив исследования.

## 6. Визуальная айдентика

### 6.1 Маскот
- Выбран: **B · Round** — круглая голова, треугольные уши с розовым нутром, открытые глаза со зрачком и бликом, нос-треугольник, w-ротик, полоски на лбу, румянец, усы.
- Состояния: base (поле/лого/чипы), sad (поражение), happy (победа — символ `cat-round-happy`: закрытые радостные глаза, открытая улыбка, приподнятые усы; та же геометрия головы).
- Единая геометрия головы во всех состояниях — обязательна для узнаваемости.

### 6.2 Лого-знак
Сетка 2×2 (рамка 4px ink, r22): два кота в клетках по главной диагонали на «лепестковых» пятнах (острый угол к центру, внешний угол r22, боковые r14); в верхне-правой клетке крестик цвета сердца **строго в центре клетки — точка (86, 34)** в viewBox 120.

### 6.3 Типографика
- Дисплей/кнопки: **Baloo 2** (700/800).
- Текст/подписи: **Nunito** (700/800).
- Подключение: Google Fonts (на релизе — self-host в бандл).

### 6.4 Палитра (токены из макета)
Светлая: bg #FDF7EE · surface #FFF · ink #443E4C · ink-soft #8A8093 · line #EBDFCC · edge #E5D6BD · accent #FF9457 (тень кнопок #E0763B) · heart #FF6B81 · good #5FBD8C · danger #E4605E · dent-deep #BCB8CE · dent-face #DFDCEA · region-line rgba(68,62,76,.45).
Регионы (пастелизованный Окабе-Ито, дальтоник-безопасный): r1 #F4C892 · r2 #A9DBF5 · r3 #93D4B8 · r4 #F5EFA3 · r5 #95B9DE · r6 #EFAC90 · r7 #E7BFD7 · r8 #D5D2CC · **r9 #C7BCE8 · r10 #9AD1DC (Р-39: расширение для 9×9–10×10; тёмная тема: #7E71AD / #5D93A3)**. Каждый регион уровня получает уникальный цвет — «1 Cat per color» читается буквально; переиспользование цветов запрещено. Порядок выбора цветов фиксированный, контраст-первый (жадный max-min по Lab): r4 → r9 → r3 → r6 → r8 → r2 → r1 → r7 → r5 → r10; уровень с k регионами использует ровно первые k токенов (похожие оттенки — стальной синий, аква — появляются только на 9×9–10×10).
Тёмная тема: см. блок `.dark` в макете (регионы притемнены вручную, dent-токены инвертированы).

### 6.5 Сердца
- Полное: без обводки; градиент #FF8E9B→#E04B58; два блика (плотный на левой доле + широкий вдоль верха); CSS drop-shadow(0 2px 3px rgba(90,60,60,.28)).
- Потраченное — «выемка»: слой-дно `--dent-deep` + слой-поверхность `--dent-face`, смещённый на (0.54, 1.2) scale(.955) → тёмный ободок-тень сверху; без бликов; **без** drop-shadow.
- Размеры: 33px в шапке поля, 45px на поражении. Сгорают справа налево.

### 6.6 Иерархия линий поля
1. Рамка поля: 3px, ink.
2. Границы регионов: 1.5px, `--region-line` (полупрозрачный) — генерируются по соседям.
3. Клеточная сетка: 1px (gap на фоне ink).

### 6.7 Язык «нажимаемости»
Интерактивные плашки: обводка 1.5px line + нижний край `0 4px 0 --edge` + просадка 3px на :active. CTA — то же с #E0763B. Статичные элементы (чипы правил, карточки) — только мягкая тень.

## 7. Технические заметки для сборки

- **Стек:** TypeScript + Svelte + Vite. Анимации — CSS keyframes. Звук — обёртка над WebAudio.

После конца пула (90) игра бесконечно циклится по сложной половине (46–90). Спад ассиста: авто-крестики стартового кота — только до уровня 20 включительно; дальше стартовый кот остаётся (Р-36 в силе), но без авто-крестиков, интро короче.
- **Рабочий процесс:** каждая итерация макета/билда — новое версионированное имя файла (среда кеширует агрессивно); публикация только после подтверждённого успеха скрипта сборки.

## 10. Коллекция котиков (будущий апдейт, post-MVP)

> **Статус: не входит в базовую версию.** Раздел описывает продуманный дизайн фичи для будущего апдейта. В коде сейчас есть только болванка: статический ростер из 10 пород (`skin.ts`), косметическая привязка «порода = регион» (`catForRegion`) и заглушка экрана (`CollectionOverlay.svelte`). Механик редкости, «первой встречи» и персистентности пока нет. Всё ниже реализуется под фиче-флагом и включается отдельным релизом.

### 10.1 Идея и петля

Коты — это не только фишки на поле, но и коллекционный контент. По мере прохождения игрок встречает всё более редкие породы; **первая встреча с породой открывает её в коллекции** (персист). Ранние уровни населены только базовой породой; чем дальше по кривой сложности (Р-38), тем выше шанс увидеть редких котов. Коллекция — чистое удовольствие/комплишн: **без валюты, без гринда, без влияния на очки/стрик**, чтобы сохранить дзен-позиционирование (§1). Петля: *в ходе решения игрок ставит кота → если это новая порода, тут же, прямо в уровне, всплывает карточка «New cat!» → порода уходит в коллекцию → на Victory — компактный рекап новых пород уровня → мотивация идти дальше и добить редких*.

### 10.2 Ростер и редкость (Р-50)

Пять тиров редкости. Финальный ростер — **20 пород**; 14 уже имеют арт (`k_*` + `k3_*`, включая Bombay=black), **6 требуют нового** (помечены `*`).

- **Common** (порог: ур. 1) — базовые «дворовые» коты: Black/Bombay, Tabby, White, Tuxedo, Cream, British Shorthair.
- **Uncommon** (~ур. 8): Calico, Siamese, Persian, Scottish Fold.
- **Rare** (~ур. 20): Bengal, Maine Coon, Ragdoll, Russian Blue*.
- **Epic** (~ур. 40): Sphynx, Abyssinian*, Norwegian Forest*.
- **Legendary** (~ур. 60 и далее в бесконечном сложном цикле пула): трио fantasy-котов — **Golden**\* (золотая шерсть), **Void**\* (чёрный «космос» со звёздами), **Cosmic**\* (галактика/туманность в окрасе). Сезонные/секретные легендарные (Santa Paws и т.п.) — позже, отдельным live-ops (см. §10.9).

Порог тира — точка на кривой сложности (Р-38): ниже него порода не выпадает вообще, сразу после — редко (см. gate ниже). Поскольку после 90 уровней пул бесконечно циклится по сложной половине (46–90), редкие и легендарные породы продолжают выпадать — коллекция достижима на длинной дистанции.

### 10.3 Состав поля (Р-49)

Число **различных** пород на доске K зависит от размера коллекции игрока U **и размера доски N**:

`K = clamp(1 + floor(U / 4), 1, Kcap)`, где `Kcap = clamp(N − 4, 2, 5)` (6×6→2, 7×7→3, 8×8→4, 9×9→5, 10×10→5), но не больше числа регионов.

Первые уровни (U мал) → **K = 1**: вся доска — одна порода (как и просил дизайн-бриф). По мере наполнения коллекции доска становится разнообразнее; большие поля допускают больше пород (просторнее — не пестрит), маленькие держат разнообразие низким ради читаемости. Каждой из K пород достаётся ≥1 регион; регионы распределяются между выбранными породами случайно.

### 10.4 Выдача пород — взвешенный дроп (Р-48)

Для каждого из K «слотов» породы тянем без повторений с весом:

`weight(b) = base[tier(b)] × gate(difficulty, tier(b)) × bias(b)`

- **base** (убывает с редкостью): Common 100 · Uncommon 45 · Rare 18 · Epic 7 · Legendary 2.
- **gate**: 0, если сложность уровня ниже порога тира; иначе плавно нарастает 0→1 за несколько уровней после порога (только-что открывшийся тир поначалу редок).
- **bias** (collection-aware, анти-фрустрация): ×2.5 для ещё не открытых **допустимых** пород, ×1 для уже открытых. Это заметно ускоряет комплишн, но открытие остаётся **вероятностным**, а не гарантированным — дзен без «обязаловки».

**Сложность** берём как позицию уровня в отсортированном пуле (Р-38) — простой и стабильный прокси.

**Сидирование ролла:** RNG сидируется `(levelId, entryNonce)`, где `entryNonce` инкрементится при каждом новом входе в уровень. Внутри одной попытки ролл **стабилен** (рестарт уровня не меняет котов — поле не «мигает» во время решения), при новом входе **ре-роллится** (луп пула даёт новые шансы на редких). Сам ролл нигде не персистится — сохраняются только факты открытия.

### 10.5 Открытие: in-level карточка + рекап на Victory (Р-47)

Открытие срабатывает **в момент успешного коммита кота** (лонг-пресс без ошибки, §2), а не на победе. Так момент радости привязан к самому действию игрока и не конфликтует с хореографией Victory.

**In-level карточка.** На успешном коммите проверяем породу региона: если её нет в `collection.discovered` — сразу показываем лёгкую карточку «New cat!» (портрет happy-позы, имя, бейдж редкости, лента «New!»). Появляется рядом с поставленным котом / по центру поля, ввод на это время мягко ставится на паузу; **тап в любом месте** или авто-таймаут (~1.5 c) закрывает карточку, и игрок продолжает решать. Несколько новых пород за уровень → каждая своя карточка в свой момент коммита.

**Персист.** Открытая порода немедленно пишется в `storage.collection` (`firstLevel`, `ts`, `count`) и **остаётся открытой, даже если уровень затем проигран** (встреча состоялась). Повторный коммит уже открытой породы — молча `count++`, без карточки.

**Стартовые коты (`givens`, Р-36).** Их ставит игра на интро, а не игрок, поэтому карточку они **не** вызывают (интро и так занято волной авто-крестиков, ввод заблокирован). Если порода стартового кота новая — открывается **молча** в момент интро и попадает в рекап на Victory.

**Рекап на Victory.** Вместо полной карточки — **компактный блок** «New cats this level»: строка мини-портретов с именами и точками-цветами редкости (только породы, открытые на этом уровне). Если новых не было — блок скрыт. Живёт рядом с карточкой стрика (Р-30) и рангом (Р-44/45), без собственной тяжёлой анимации.

**Тайминг очков.** Пауза на время показа in-level карточки **исключается из активного времени** «Your time» (консистентно с QA KC-5: интро/паузы/реклама не считаются).

**`prefers-reduced-motion`** — карточка появляется статично, без анимаций (консистентно с §5.5).

### 10.6 Экран коллекции (Р-51)

Апгрейд `CollectionOverlay.svelte`:

- **Обрамление портретов — squircle** (скруглённый квадрат ~26% радиуса), не круг: сидящие коты садятся в форму естественнее (см. макет окон, вариант B). Единый стиль портретов во всех окнах фичи.
- Шапка с прогрессом «X / N собрано».
- Секции/группировка по редкости (Common → Legendary), цветовое кодирование тиров.
- **Неоткрытые**: силуэт (CSS-фильтр из спрайта, отдельный арт не нужен) + «???» + точка-цвет редкости — намёк, но не спойлер.
- **Открытые**: портрет + имя + подпись тира + «×N встреч» + «впервые: Lvl M».
- Пометка «NEW» на только что открытых, пока игрок не посмотрел карточку в коллекции.

### 10.7 Данные, код, тесты (Р-52)

- **Персист:** ключ `collection` добавляется в `KEYS` (`storage.ts`). Формат: `{ v: 1, discovered: Record<breedId, { firstLevel: number; ts: number; count: number }> }`. Миграций нет (новый ключ).
- **Новый модуль `lib/collection.ts`:** ростер (id, имя, тир, спрайты idle/happy), конфиг тиров (base-вес, порог, рампа, цвет), `assignBoardBreeds(level, ctx)` → `Map<regionId, breedId>` (сидированный), `discoverBreed(breedId, levelId)` → `true`, если порода была новой (вызывается на успешном коммите и молча — на `givens` интро), `getCollectionState()`, `getLevelNewBreeds(levelId)` для рекапа, формула K, метаданные редкости.
- `skin.ts`: остаётся источником спрайтов; `catForRegion` понижается до fallback-скина (используется, пока фича выключена). Под флагом `Board.svelte` берёт карту пород из `collection.ts` вместо `catForRegion`. `RuleChips` продолжает использовать фиксированную базовую породу.
- **Новый компонент `NewCatCard.svelte`** — in-level карточка «New cat!», монтируется в `GameScreen.svelte`/`Board.svelte`, триггерится из логики успешного коммита (`game.ts`) с паузой ввода. **Компактный блок-рекап** «New cats this level» — отдельный лёгкий компонент (или блок внутри `VictoryScreen.svelte`).
- **Тесты `tests/collection.test.ts`:** gate (нет Rare/Epic/Legendary ниже порога); детерминизм (одинаковый сид → одинаковая карта; рестарт стабилен, новый вход ре-роллит); масштабирование K по U; открытие на коммите и дедуп (повтор не даёт карточку); открытие сохраняется при проигрыше; `givens` открываются молча; рекап перечисляет ровно новые породы уровня; bias повышает шанс не открытых.
- Всё под **фиче-флагом**, чтобы не попасть в базовую версию.

### 10.8 Ассеты (Р-53)

- **Happy-позы** для reveal и победной волны: сейчас в `skin.ts` `idle = happy` (заглушка) — нужен отдельный лист happy на весь ростер.
- **6 новых пород**: Russian Blue (Rare), Abyssinian, Norwegian Forest (Epic), Golden, Void, Cosmic (Legendary) — к 14 существующим concept-спрайтам (`k_*` + `k3_*`).
- **Силуэты** для неоткрытых выводятся CSS-фильтром — доп. арт не требуется.
- **Бейджи редкости** — CSS/токены (добавить цвета тиров в палитру §6.4).

### 10.9 Решения по вопросам дизайна (согласовано)

- **Монетизация — нет.** Коллекция не-монетизирована ради дзена; вся монетизация — как в §4 (без изменений).
- **Формула K — от U и размера доски** (см. §10.3 / Р-49).
- **Карточки — только имя + редкость**, без флейвор-текстов (меньше локализации; §10.6).
- **Легендарные — трио fantasy** (Golden / Void / Cosmic) в стартовом апдейте; сезонные/секретные — позже live-ops.
- **Ростер — 20 пород** (см. §10.2), 6 требуют нового арта + happy-лист на весь ростер.

**Отложено на live-ops (после старта фичи):** сезонные/секретные легендарные (напр. Santa Paws в декабре) — нужна система календаря/скрытых триггеров и события.
