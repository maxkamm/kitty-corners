# Kitty Corners — Game Design Document
**Сборочная версия.** Обновлено: 08.07.2026.
Источник истины по UI: макет `kitty-corners-screens-v22.html` (лежит рядом). При расхождении текста и макета приоритет у макета.

---

## 1. Концепция

- Жанр: логическая головоломка, клон LinkedIn Queens / Star Battle 1★.
- Тема: коты; каждый кот занимает «свою территорию».
- Позиционирование: **дзен** — без таймера, без давления; спокойная казуальная сессия.
- Платформа: **Playgama** (web), mobile-first, портрет.
- Название: **Kitty Corners** — тройной смысл: кошачьи уголки + идиома kitty-corner («по диагонали», ключевое правило) + отсылка к народной игре. Отклонены: Cat Queens (коллизия + казино-SEO), Catnook.
- Визуальный жанр: casual-cute в духе MeowDoku, но с собственной айдентикой (см. §6). Прямое копирование чужого арта запрещено.

## 2. Правила и управление

Правила (тексты в игре — EN, как в чипах над полем):
1. **1 Cat per color** — ровно один кот в каждом цветном регионе.
2. **1 Cat per column and row** — ровно один кот в каждой строке и каждом столбце.
3. **Cats cannot touch** — коты не касаются даже по диагонали.

Управление:
- Тап по клетке — поставить/снять крестик (ручная разметка).
- **Лонг-пресс ~350–400 мс** с анимацией «кольца зарядки» — коммит кота в клетку.
- Ошибочный коммит → −1 сердце + визуальный отклик. Коммит верен только если клетка входит в единственное решение уровня: у каждого кота ровно одно легальное место. Любая другая постановка — ошибка (−1 сердце), даже если она пока не конфликтует с уже стоящими котами. Это исключает тупики из локально-легальных, но неверных ходов (ср. QA KC-4); честно, т.к. все уровни решаются солвером логикой без угадывания.

Сознательно отсутствуют (скилл-слой, решение зафиксировано): авто-тени от котов, undo, ластик-режим. Ручная разметка — часть мастерства игрока.

**Стартовый кот (Р-36):** уровень начинается с как минимум одного предустановленного кота (клетка из решения; по умолчанию — кот самого маленького или второго по маленькости региона, чередуется по чётности id уровня: мини-регионы — самые зажатые, отдавать их бесплатно выгоднее для интереса; переопределяется полем `givens` в данных уровня). Он неснимаем. При открытии уровня играет интро: анимация появления кота → с небольшой задержкой от него во все стороны волной прорисовываются авто-крестики (его строка/столбец/регион/соседи). Эти крестики — обычные пометки (игрок может их снять). Исключение из запрета авто-теней: действует только для стартового кота в момент интро; ввод на время интро заблокирован; при prefers-reduced-motion интро пропускается.

### 2.1 Туториал (Р-41)

Первый запуск: Play → слайды «How to play» (3 карточки: правила / управление / сердца-стрик) → guided-уровень 4×4 → обычный Level 1. Кнопка Skip в шапке guided-уровня; флаг `tutorialDone` персистится — повторно не показывается. Слайды доступны всегда: «?» на главной и «How to play» в настройках (единый компонент).

Guided-уровень — заскриптованная песочница без сердец, рекламы и таймера (`src/lib/tutorial.ts`): ручной 4×4 с уникальным решением, стартовый кот с интро-волной как в бою; шаги ведут по реальной цепочке дедукций уровня — «у региона осталась одна клетка» (лонг-пресс кота), ручные крестики по следствиям кота (тап), финальный кот → волна радости → «Start Level 1». Ввод ограничен подсвеченными клетками (persistent-пульс), неверные действия молча игнорируются. Консистентность скрипта и уровня закреплена тестом `tests/tutorial.test.ts`.

## 3. Сердца, стрик, поражение

- 3 сердца на уровень. Потеря сердца не ломает стрик.
- 0 сердец → экран поражения. Иерархия действий (Р-25):
  1. **Rewarded «Get +1 ♥ and keep going»** — доминирующая кнопка (revive, приоритет по текущему макету).
  2. «Restart level» — вторичная.
  3. «Quit to menu» — тихая ссылка.
- Предупреждение на экране: «Your N level streak will end here».
- Стрик ломается рестартом/выходом после полного слива сердец; revive его сохраняет.

> ⚠️ **Флажок перед сабмитом:** ранее фиксировался конфликт revive-механики с политикой Playgama (тогда решением была замена на «Skip level»). Текущий макет возвращает «+1 ♥» как приоритетный. Сверить с актуальной политикой платформы до релиза.

### 3.1 Очки (Р-42)

За победу: **очки = База × Время × Чистота × Глазомер × Помощь**, округление до 5. Поражение и skip очков не дают. Кумулятивная сумма `totalScore` персистится — будущее значение лидерборда Playgama; каждый номер уровня набирается один раз (номер растёт только на победе). Стрик на очки не влияет.

- **База** = 100 × `meta.steps` уровня (шаги солвера, 10–26): сложность оплачивается автоматически.
- **Время**: пар = 12 × steps сек; множитель `clamp(1.5 − 0.5·t/par, 0.5, 1.5)` — медленная игра не обнуляет очки (дзен), только теряет бонус.
- **Чистота**: 0 ошибок ×1.0, одна ×0.6, две ×0.35.
- **Глазомер**: доля самостоятельно помеченных ✕-клеток r = xCells/(n²−n); множитель 1 + 0.4·(1−min(r,1)). Бонус, не штраф: разметка — легитимное мастерство (§2). Авто-крестики стартового кота не считаются; снятие пометки её «не возвращает».
- **Помощь**: хинт ×0.8 за каждый, автокот ×0.5 — очки нельзя купить просмотром рекламы.

Идеал ~2.1 × базы. Показ: пилюля на Victory (+очки и Total). Реализация: `src/lib/score.ts` (чистый модуль, тесты `tests/score.test.ts`); счётчики прогона в `game.ts`.

## 4. Монетизация

100% реклама через **Playgama Bridge SDK**:
- **Interstitial** на границах уровней; таймаут показа 180 с.
- **Rewarded video**: (а) «+1 ♥» на экране поражения; (б) лампочка-хинт; (в) автокот (см. §5.2). У rewarded-элементов бейдж «▸ ad».
- Премиум-тира нет.

## 5. Экраны (спека по макету v22)

### 5.1 Main
- Верх: иконки-кнопки настройки (слева) и «?» (справа).
- Центр: лого-знак 136px + словомарка «Kitty / Corners» (вторая строка акцентная), теглайн «a cozy logic puzzle».
- Фон: диагональная дорожка лапок (фирменный мотив, opacity 50%).
- Низ: чип стрика (пламя + «N level streak»), CTA **Play** с подписью «Level N».
- Баннеров нет.

### 5.2 Board (игровой экран)
- Шапка: «Level N» (слева) · сердца 33px (центр) · шестерёнка (справа).
- Полоса правил: 3 чипа «мини-сетка 3×3 (40px) + текст» (реф-компоновка):
  - per color: голубой регион-лесенка, кот внутри, крестики на остальных клетках региона;
  - column and row: кот сверху-в-центре, крестики по его строке/столбцу;
  - cannot touch: кот в центре, все 8 соседей закрещены.
  Чипы плоские (без объёмного края) — «нажимаемость» зарезервирована за кнопками.
- Поле: квадрат, внешняя рамка 3px ink r14. Продовые размеры 6×6–10×10. Максимум поля: 372px для 6×6–8×8, 44·N px для 9×9–10×10 (клетка ≥40px гарантируется при достаточной ширине вьюпорта; на узких экранах ~390px клетка 10×10 ужимается до ~35px — компромисс по QA KC-2). Поле дополнительно ограничено доступной высотой (ландшафт/низкие iframe, QA KC-1).
- Низ: **две круглые кнопки 60px** (акцент, физика проседания, бейдж «▸ ad» снизу по центру):
  - голова кота — **автокот**: ставит одного верного кота (предложение: лимит 1/уровень, дальше кнопка гаснет);
  - лампочка — **хинт**: следующий логический шаг из лога солвера.
- Таймер не показывается (время меряется скрыто, отчёт на победе).

### 5.3 Settings (оверлей = пауза)
- Поле под оверлеем: blur(6px) + затемнение.
- Дефолты тумблеров: Sound — on, Vibration — off, Pattern marks — off.
- Лист: Continue (CTA) · тумблеры Sound / Vibration / **Pattern marks** (запасное кодирование регионов для дальтоников) · How to play · Restart level (красный, требует подтверждения) · Quit to menu (ссылка).

### 5.4 Defeat
- Грустный маскот (Round-sad: прикрытые глаза, слеза, поникшие усы, приглушённый румянец).
- Три сердца-выемки 45px → заголовок «Out of hearts» → плашка-предупреждение о стрике → кнопки по иерархии §3.

### 5.5 Victory
- Маскот Round → «Level N done!».
- **Карточка Win streak** (фичекарта, реф Arrows): заголовок капсом без иконки → крупное пламя + число + «+1» (pop-анимация) → трек узлов-лапок (пройденные / текущий укрупнённый с анимацией / следующий пунктиром, подписи-номера) → «Best streak · N».
- Прогресс (номер уровня) сохраняется в момент победы, не по «Next level» (QA KC-3); «Your time» считает только активную игру — без интро, паузы, рекламы и экрана поражения (QA KC-5).
- Пилюля «Your time M:SS». Кнопка «Next level». Конфетти (отключается при prefers-reduced-motion).

### 5.6 Cat lab (внутренний инструмент, в прод НЕ идёт)
Экран выбора маскота из 11 вариантов с превью 88/44/26px и живым применением. Оставлен в макете как архив исследования.

## 6. Визуальная айдентика

### 6.1 Маскот
- Выбран: **B · Round** — круглая голова, треугольные уши с розовым нутром, открытые глаза со зрачком и бликом, нос-треугольник, w-ротик, полоски на лбу, румянец, усы.
- Состояния: base (поле/лого/чипы), sad (поражение), happy (победа — символ `cat-round-happy`: закрытые радостные глаза, открытая улыбка, приподнятые усы; та же геометрия головы).
- Единая геометрия головы во всех состояниях — обязательна для узнаваемости.

### 6.2 Лого-знак
Сетка 2×2 (рамка 4px ink, r22): два кота в клетках по главной диагонали на «лепестковых» пятнах (острый угол к центру, внешний угол r22, боковые r14); в верхне-правой клетке крестик цвета сердца **строго в центре клетки — точка (86, 34)** в viewBox 120.

### 6.3 Типографика
- Дисплей/кнопки: **Baloo 2** (700/800).
- Текст/подписи: **Nunito** (700/800).
- Подключение: Google Fonts (на релизе — self-host в бандл).

### 6.4 Палитра (токены из макета)
Светлая: bg #FDF7EE · surface #FFF · ink #443E4C · ink-soft #8A8093 · line #EBDFCC · edge #E5D6BD · accent #FF9457 (тень кнопок #E0763B) · heart #FF6B81 · good #5FBD8C · danger #E4605E · dent-deep #BCB8CE · dent-face #DFDCEA · region-line rgba(68,62,76,.45).
Регионы (пастелизованный Окабе-Ито, дальтоник-безопасный): r1 #F4C892 · r2 #A9DBF5 · r3 #93D4B8 · r4 #F5EFA3 · r5 #95B9DE · r6 #EFAC90 · r7 #E7BFD7 · r8 #D5D2CC · **r9 #C7BCE8 · r10 #9AD1DC (Р-39: расширение для 9×9–10×10; тёмная тема: #7E71AD / #5D93A3)**. Каждый регион уровня получает уникальный цвет — «1 Cat per color» читается буквально; переиспользование цветов запрещено. Порядок выбора цветов фиксированный, контраст-первый (жадный max-min по Lab): r4 → r9 → r3 → r6 → r8 → r2 → r1 → r7 → r5 → r10; уровень с k регионами использует ровно первые k токенов (похожие оттенки — стальной синий, аква — появляются только на 9×9–10×10).
Тёмная тема: см. блок `.dark` в макете (регионы притемнены вручную, dent-токены инвертированы).

### 6.5 Сердца
- Полное: без обводки; градиент #FF8E9B→#E04B58; два блика (плотный на левой доле + широкий вдоль верха); CSS drop-shadow(0 2px 3px rgba(90,60,60,.28)).
- Потраченное — «выемка»: слой-дно `--dent-deep` + слой-поверхность `--dent-face`, смещённый на (0.54, 1.2) scale(.955) → тёмный ободок-тень сверху; без бликов; **без** drop-shadow.
- Размеры: 33px в шапке поля, 45px на поражении. Сгорают справа налево.

### 6.6 Иерархия линий поля
1. Рамка поля: 3px, ink.
2. Границы регионов: 1.5px, `--region-line` (полупрозрачный) — генерируются по соседям.
3. Клеточная сетка: 1px (gap на фоне ink).

### 6.7 Язык «нажимаемости»
Интерактивные плашки: обводка 1.5px line + нижний край `0 4px 0 --edge` + просадка 3px на :active. CTA — то же с #E0763B. Статичные элементы (чипы правил, карточки) — только мягкая тень.

## 7. Технические заметки для сборки

- **Стек:** TypeScript + Svelte + Vite. Анимации — CSS keyframes. Звук — обёртка над WebAudio.
- **Поле:** CSS Grid. Обязательно задавать **и** `grid-template-columns`, **и** `grid-template-rows` = `repeat(N, 1fr)`; контент клетки (SVG кота/крестика) позиционировать **absolute** в процентах. Урок бага: SVG имеет intrinsic-размер 300×150, а проценты высоты в авто-контейнере не разрешаются → ряды раздуваются и поле «обрезается до 3 рядов».
- **Границы регионов:** для клетки (r,c) — по каждому из 4 соседей: если регион отличается, добавить `inset ±1.5px … var(--region-line)` в box-shadow. Референс: `buildBoard()` в макете. Алгоритм не зависит от размера поля.
- **Ассеты:** все SVG-символы уже в макете, ids: `cat-round` (+ inline sad-версия на экране Defeat), архив маскотов `cat-loaf/chibi/peek/square/lounge/belly/melt/clay/poly/vinyl`, иконки `ic-heart-full`, `ic-heart-empty`, `heart-path`, `ic-flame`, `ic-paw`, `ic-gear`, `ic-q`, `ic-play-ad`, `ic-cathead`, `ic-bulb`, `soft-x`; градиенты `catG`, `flameG`, `heartRedG`, `clayG`, `vinylG`. Извлекать в спрайт/компоненты как есть.
- **Темизация:** через CSS custom properties (:root / .dark). Не хардкодить цвета вне токенов; исключения — сердца и пламя (намеренно теманезависимы).
- **Хранилище:** слой-абстракция storage: dev → localStorage, релиз → Bridge Storage. Bridge SDK подключается только на релизном этапе через адаптер.
- **Аналитика:** в MVP отсутствует; заложить интерфейс-заглушку.
- **Уровни (Р-37):** пул из 90 предгенерированных уровней (6×6·20, 7×7·20, 8×8·20, 9×9·15, 10×10·15), отсортированных по размеру и числу шагов солвера; нумерация уровней идёт по пулу, после конца — по кругу (до внедрения кривой сложности). Генератор: `game/tools/generate-levels.ts` (solution-first: расстановка котов → рост регионов от котов с принудительными мини-регионами → проверка единственности брутфорсом → решаемость игровым солвером без гаданий → раскраска). Формат уровня: `regions` — строки-ряды с id регионов (a–j), `colors` — маппинг id → токен палитры r1–r10, уникальный цвет каждому региону (Р-39). Солвер (общий модуль игры и генератора) знает три техники: единственная клетка в группе; регион, запертый в строке/столбце; исключение клеток, лишающих чужую группу кандидатов.
- **Кривая сложности (Р-38):** каждому уровню считается скор `(size−6)·12 + шаги солвера + 2·confined + 4·starve`; пул отсортирован по скору (размеры пересекаются: сложный 6×6 может идти позже простого 7×7), внутри окон по 5 — лёгкое перемешивание для разнообразия; уровень 1 — минимальный скор. После конца пула (90) игра бесконечно циклится по сложной половине (46–90). Спад ассиста: авто-крестики стартового кота — только до уровня 20 включительно; дальше стартовый кот остаётся (Р-36 в силе), но без авто-крестиков, интро короче.
- **Рабочий процесс:** каждая итерация макета/билда — новое версионированное имя файла (среда кеширует агрессивно); публикация только после подтверждённого успеха скрипта сборки.

## 9. Реестр решений этой итерации

- Р-28. Маскот: **B · Round**; sad-вариант на поражении; единая геометрия головы.
- Р-29. Лого: лепестковые пятна остриями к центру; крестик в центре клетки (86,34).
- Р-30. Экран победы: фичекарта Win streak (Arrows-style) + **Best streak на экране результата** (закрывает старый открытый вопрос о месте рекорда).
- Р-31. Панель помощи: две круглые rewarded-кнопки — автокот + хинт (вместо одной кнопки Hint). Предложение к балансу: автокот ≤1/уровень.
- Р-32. Сердца: эмодзи-объём для полных, «выемка» для потраченных; сгорают справа налево.
- Р-33. Чипы правил: горизонтальные, мини-сетка 3×3 + текст (по рефу); крестики в чипах — как на поле (ink).
- Р-34. Контур регионов: 1.5px полупрозрачный (`--region-line`), подчинён рамке поля.
- Р-35. Поражение: rewarded **«+1 ♥»** приоритетом по макету (суперсидит прежнее решение о skip-level; см. флажок в §3).
- Р-39. Цвета регионов: уникальный цвет каждому региону, палитра расширена до r10; правило «1 Cat per color» буквально соответствует полю.
- Р-38. Кривая сложности: скор-сортировка пула с окнами-перемешиваниями, бесконечный цикл по сложной половине после 90, авто-крестики только до уровня 20 (детали в §7).
